# reference-docs

Reference and customer documents and files. They are **not** part of the application code.

- This folder and all `*.md` files are committed to git and pushed to GitHub.
- They are **never deployed** to a server (see the deploy section in the main `README.md`).

| File | What it is |
|---|---|
| `api-usage.md` | Complete manual of the Bills API, with examples |
| `zohal-api-1.json` | Zohal API documentation (OpenAPI), from the provider |
| `zohal-api-token.txt` | Zohal API token. **Secret. Ignored by git. Do not commit.** |
